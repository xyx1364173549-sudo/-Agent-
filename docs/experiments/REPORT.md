# 实验报告（论文第 6 章素材）

三组实验的汇总：方法、数据、结果、结论。原始数据在各 `exp*.json`，图表在 `charts/`。

## 实验一：分层记忆消融

**问题**：分层记忆到底能不能让回答更贴合学生？

**方法**：同一位学生的同一批学习轨迹，按三个条件逐步加料，回答 3 个只能
靠「了解这个学生」才能答好的问题。每个回答的要点覆盖率由模型判定
（要点清单见 `src/eval/dataset.py` 的 `PROFILE_QUESTIONS`）。

| 条件 | 上下文长度 | 要点覆盖率 |
| --- | --- | --- |
| 无记忆 | 15 字 | 0.4444 |
| 仅工作记忆 | 197 字 | 0.6667 |
| 全分层记忆 | 352 字 | 0.8889 |

**结论**：要点覆盖率随记忆层次单调递增。仅工作记忆相对无记忆提升 50%，
全分层记忆提升 100%。其中「我最近的学习情况怎么样」一题差异最大
（0.00 → 0.33 → 1.00）——这类需要事实数据的问题，只有情景记忆和画像
才能支撑。

**注意点**：仅 3 个问题 × 3 个要点，样本量小。结论用于说明趋势，
不宜外推到一般场景。运行该实验会真实调用模型（18 次调用）。

## 实验二：切分策略 × 检索策略

**问题**：3 种切分 × 3 种检索，哪组搭配最好？

**方法**：8 篇学习资料、16 条查询（按与目标文档的字面重叠度分高 / 中 /
低三档，重叠度由 `literal_overlap` 客观计算），top_k=2。

**结果**（Hit@2）：

| 切分策略 | 关键词 | 向量 | 混合 |
| --- | --- | --- | --- |
| 固定长度 | 0.833 | 0.500 | 0.833 |
| 递归 | 0.778 | 0.444 | 0.722 |
| 语义 | 0.833 | 0.333 | 0.778 |

**结论（与常见认知相反，但数据如此）**：当前配置下**关键词检索最好**，
混合次之，向量最差。原因有二：

1. 本项目采用的本地向量模型（all-MiniLM-L6-v2）是**英文模型**，对中文
   语义的理解能力有限（M3 已用 xfail 固定此局限）；
2. 中文二元组关键词匹配在短文档上覆盖率不低，且中文技术资料的领域词
   集中，查询与文档的字面重叠天然偏高。

**改进方向**：更换中文向量模型（BGE / text2vec）后重跑本实验，
向量检索的低重叠查询优势应能体现。

**实验设计修正**（写论文时值得交代）：初版 top_k=3，8 篇资料取 3 条
导致天花板效应（各策略均 1.0 满分、无区分度），改为 top_k=2。
另曾尝试将查询二分「字面型 / 语义型」，实测分不开（中文查询重叠度普遍
在 0.15 以上），改为按重叠度连续分档。

零 API 调用（向量与关键词检索全在本地），可任意重跑。

## 实验三：动态规划 vs 静态路径

**问题**：动态任务规划比固定课表好在哪？

**方法**：30 次蒙特卡洛仿真（固定种子序列，结果可复现）。仿真学生具备
三个真实特征：**依赖约束**（前置没学会时练后面无效）、**遗忘**（掌握度
随时间按半衰期 30 天衰减）、**学习目标**（只需掌握递归链 4 个知识点）。
动态规划走 `src/planning/planner.py` 的真实算法，静态路径按大纲顺序轮转。

| 指标 | 静态路径 | 动态规划 |
| --- | --- | --- |
| 目标知识点均分 | 0.2332 | 0.6200（+166%） |
| 有效练习占比 | 0.5000 | 0.9989 |
| 目标达标数（满分 4） | 0.00 | 2.70 |

**结论**：在同样 30 轮预算下，动态规划的目标达成显著优于静态课表。
静态课表一半的练习是**无效的**——按大纲顺序轮转到「返回值合并」时，
它的前置「调用过程」还没学会，练了也白练。

**这个实验揪出的真实缺陷**：初版仿真的结果是**反的**（动态更差 0.11），
根因是**画像的掌握度从不衰减**——库里存着「三个月前练到 0.8」，规划器
就再也不安排它了。修复：掌握度按半衰期 30 天**读取时衰减**（存原值、
读时算），`LearnerProfile` 支持注入时钟，规划排序按衰减后的现值。
详见 `src/planning/profile.py` 的模块说明。

**局限**：仿真学生的参数（增益 0.28、噪声、目标 0.7）是估计值，结论的
定量数值不宜直接外推；但「依赖约束 + 遗忘 + 目标」三个定性机制是真实的。

零 API 调用，可任意重跑。
